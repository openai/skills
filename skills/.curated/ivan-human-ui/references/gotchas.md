# Gotchas

## 1) Vague Output Kills Quality

- Wrong: "make it more premium", "optimize logic", "looks better now".
- Correct: explicit class/token/value edits and measurable before/after checks.

## 2) Color Drift To Default AI Palette

- Watch for accidental indigo/purple/emerald defaults in generated UI.
- Keep palette aligned with neutral/product direction unless brand requires otherwise.

## 3) Missing Media Is A Hard Fail

- If any required visual track (animal/abstract/business) is missing, treat as failed handoff.
- Always run visibility checks before final output.

## 4) Border + Shadow Muddy Stacking

- Avoid solid border plus heavy shadow combinations that reduce edge clarity.
- Prefer low-opacity outer/inset ring + restrained shadow.

## 5) Trigger Scope

- Do not use this skill for backend-only changes.
- Do not use this skill for non-visual tasks like pure data modeling or infra setup.
