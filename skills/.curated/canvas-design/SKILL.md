# Canvas Design

## Overview

Use this skill when the deliverable should feel like a designed object: a poster, cover, flyer, single-page visual statement, or static branded announcement. The goal is not generic decoration; it is a composed visual artifact with clear hierarchy, restraint, and atmosphere.

## Workflow

1. Reduce the brief to three things before making anything:
   - visual thesis
   - content hierarchy
   - format and output size
2. Decide whether the artifact is primarily typographic, image-led, collage-driven, or shape-driven.
3. Build one dominant composition first, then add supporting detail only where it improves hierarchy or mood.
4. Keep copy sparse and structural. Text should behave like design material, not a paragraph dump.
5. Polish spacing, contrast, alignment, and margin discipline before exporting.

## Design Rules

- Use one clear visual idea per artifact.
- Prefer 1-2 typefaces with distinct roles.
- Let scale, whitespace, alignment, and crop do more work than decorative effects.
- Choose a controlled palette. One accent color is usually enough.
- Make the first read immediate: title, focal visual, or key message should register in seconds.
- Keep all elements inside the canvas with breathing room and intentional margins.

## Output Guidance

- Prefer PNG, PDF, or SVG outputs for static deliverables.
- If multiple directions would help, produce 2-3 clearly different concepts instead of many minor variations.
- If the work needs to become a website or app surface, switch to the `$frontend-skill` when it is available.

## Guardrails

- Do not copy a living artist's recognizable style directly; translate the requested qualities into original work.
- Do not overload the page with too many motifs, type styles, or effects.
- Do not let supporting text overpower the composition.
- Do not default to generic card layouts or UI patterns; this skill is for static visual design, not product UI.

## Deliverables

- The final static artifact
- A short note describing the chosen visual direction
- Optional alternate directions when the brief benefits from comparison
